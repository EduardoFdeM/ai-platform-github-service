# Como usar esta pasta

1. Faça upload desta pasta/ZIP no Codex.
2. Peça para ele ler `PROMPT_DEFINITIVO.md` e executar exatamente as instruções.
3. Antes da versão final da apresentação, adicione os assets que ainda faltam:
   - `assets/07-figma-overview.png`
   - `assets/08-figma-flow.png`
   - opcional: `assets/09-github.png`
   - opcional: print final do Miro/perfis.
4. Se você corrigir o filtro do Kanban para exibir apenas User Stories, substitua `assets/03-kanban-overview.png` pelo novo print mantendo o mesmo nome.
5. O Codex deve salvar os arquivos finais em `output/`.
